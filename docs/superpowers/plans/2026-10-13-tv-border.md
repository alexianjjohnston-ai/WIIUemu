# TV Border During Play Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On Windows, while any Wii Remote phone has camera pointing on, the screen showing Cemu turns black with the
AprilTag squares around the edge, and Cemu's game window sits in the middle. When the cameras stop, Cemu goes back
to normal.

**Architecture:**
- **Pure parts** (all platforms, unit-tested): the pixel layout of tags and game area (`wiiu-tracking`), the
  on/off controller, the choice of Cemu's main window by title, and the recovery-file rules (`wiiu-connect`).
- **Win32 calls** (Windows only) live in `wiiu-desktop-sys`, the repo's place for `unsafe` FFI: listing windows,
  the border window, saving, placing and restoring Cemu's window.
- **A `tv-border` thread** in `wiiu-connect` ties them together through a `Desktop` trait, so the driver logic is
  tested with a fake on every platform.

**Tech Stack:** Rust, `windows-sys` 0.61, axum (setup API), the setup page (`web/setup.html`), TypeScript (one phone
hint).

**Spec:** `docs/adr/0004-tv-border-during-play.md`

## Global Constraints

- Layout: `MarkerLayout::border(&BorderConfig::default())`, drawn exactly like `web/tracking.html`. A margin of 2 % of
  `min(width, height)`, a 1-cell white quiet zone around each tag (cell = tag edge / 8), and the bounding box of all
  tags plus quiet zones scaled to fit and centred.
- Cemu's main window is the visible top-level window of a `Cemu.exe` process whose title starts with `"Cemu "`
  (Cemu `src/Common/version.h`, `src/gui/wxgui/wxWindowSystem.cpp`). Never choose by size.
- Auto mode: on while ≥ 1 Wii Remote camera sent a frame in the last 1.5 s; off 3 s after the last one.
- Every change to Cemu's window is written to `tv-border-restore.json` in the data folder **before** it is made,
  and restored on hide, on shutdown and on the next start (same pid and start time only).
- Setting values: `auto` (default), `on`, `off`. Stored with the setup state. Changed through a CSRF-checked
  setup API.
- The exe is per-monitor DPI aware (manifest `PerMonitorV2`), so window coordinates are physical pixels.
- `unsafe` only in `wiiu-desktop-sys`. Linux and macOS compile the pure parts; the driver there reports
  `unsupported`.
- Run `cargo fmt --all --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`
  and the phone checks before every commit; never run prettier in `apps/phone`;
  `git checkout -- apps/phone/screenshots` after e2e runs.

## Review Focus

1. **Cemu not running, or still on its game list (no game started):** the border still shows around the main
   window, because the main window exists from start-up. With no Cemu window at all, the status reads "Waiting for
   Cemu's game window" and nothing else changes. Test: driver with a fake desktop that has no Cemu window (Task 5).
2. **Cemu closed while the border shows:** the border closes, nothing is restored onto a dead window, and the
   recovery file is deleted. Test: Task 5 (fake reports the window gone).
3. **Display scaling 125–200 %** (common on TVs and laptops): the game area must still match the tags. The manifest
   declares per-monitor DPI awareness, and the Windows test sets it for the test process. Test: Task 4 (stand-in
   window, client rect checked in physical pixels).
4. **Wii U Connect killed while the border shows:** on the next start Cemu gets its title bar, menu and size back.
   Test: the recovery path with the stand-in window (Task 4) plus pure rules (Task 3).
5. **A phone connects and drops for a second:** no flicker; the border stays for 3 s. Test: controller (Task 2).

```rust
//! Where the game and the tags go on a real screen, in pixels: the same math as `web/tracking.html`, so the TV
//! border window (Windows) and the browser page draw identical borders.

use crate::markers::MarkerLayout;
use crate::tags;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct PixelRect {
    pub left: i32,
    pub top: i32,
    /// Exclusive.
    pub right: i32,
    /// Exclusive.
    pub bottom: i32,
}

impl PixelRect {
    pub fn width(&self) -> i32 {
        self.right - self.left
    }
    pub fn height(&self) -> i32 {
        self.bottom - self.top
    }
    fn overlaps(&self, o: &PixelRect) -> bool {
        self.left < o.right && o.left < self.right && self.top < o.bottom && o.top < self.bottom
    }
}

#[derive(Debug, Clone, PartialEq)]
pub struct ScreenLayout {
    /// The game image (Cemu's client area goes here).
    pub game: PixelRect,
    /// White tag cells (quiet zones and data bits); everything else on the screen is black.
    pub white: Vec<PixelRect>,
}

pub fn screen_layout(width: u32, height: u32, layout: &MarkerLayout) -> Option<ScreenLayout> {
    if width == 0 || height == 0 || layout.markers.is_empty() {
        return None;
    }
    let (w, h) = (width as f64, height as f64);
    // Bounding box of all tags incl. their 1-cell quiet zone, in game-height units (x scaled by aspect).
    let (mut min_x, mut min_y, mut max_x, mut max_y) = (f64::MAX, f64::MAX, f64::MIN, f64::MIN);
    for m in &layout.markers {
        let [bl, br, _, tl] = m.corners;
        let cell = (bl[1] - tl[1]) / 8.0;
        min_x = min_x.min(tl[0] * layout.aspect - cell);
        max_x = max_x.max(br[0] * layout.aspect + cell);
        min_y = min_y.min(tl[1] - cell);
        max_y = max_y.max(bl[1] + cell);
    }
    let margin = 0.02 * w.min(h);
    let s = ((w - 2.0 * margin) / (max_x - min_x)).min((h - 2.0 * margin) / (max_y - min_y));
    let ox = (w - (max_x - min_x) * s) / 2.0 - min_x * s;
    let oy = (h - (max_y - min_y) * s) / 2.0 - min_y * s;
    let px = |x: f64, y: f64| (ox + x * layout.aspect * s, oy + y * s);
    let r = |v: f64| v.round() as i32;
    let (gx0, gy0) = px(0.0, 0.0);
    let (gx1, gy1) = px(1.0, 1.0);
    let game = PixelRect { left: r(gx0), top: r(gy0), right: r(gx1), bottom: r(gy1) };
    let mut white = Vec::new();
    for m in &layout.markers {
        let cells = tags::render(m.id as usize)?;
        let tl = m.corners[3];
        let (bx, by) = px(tl[0], tl[1]);
        let (ex, _) = px(m.corners[1][0], 0.0);
        let cell = (ex - bx) / 8.0;
        for (row, line) in cells.iter().enumerate() {
            for (col, &is_white) in line.iter().enumerate() {
                if is_white {
                    let (c, rr) = (col as f64, row as f64);
                    white.push(PixelRect {
                        left: r(bx + (c - 1.0) * cell),
                        top: r(by + (rr - 1.0) * cell),
                        right: r(bx + c * cell),
                        bottom: r(by + rr * cell),
                    });
                }
            }
        }
    }
    Some(ScreenLayout { game, white })
}
```
  Re-export in `lib.rs`: `pub use screen::{screen_layout, PixelRect, ScreenLayout};`

```rust
pub struct Controller {
    /// When cameras were last seen (Auto).
    last_camera: Option<Instant>,
}

impl Controller {
    pub fn new() -> Self {
        Self { last_camera: None }
    }

    pub fn want_shown(&mut self, mode: TvBorderMode, cameras: usize, now: Instant) -> bool {
        match mode {
            TvBorderMode::Off => false,
            TvBorderMode::On => true,
            TvBorderMode::Auto => {
                if cameras > 0 {
                    self.last_camera = Some(now);
                }
                self.last_camera.is_some_and(|t| now.saturating_duration_since(t) < HIDE_DELAY)
            }
        }
    }
}
```

```rust
/// A slot counts as "camera on" this long after its last camera frame (TV border, ADR-0004).
pub const CAMERA_ACTIVE_WINDOW: Duration = Duration::from_millis(1500);

pub fn cameras_active(&self, now: Instant) -> usize {
    self.lock()
        .slots
        .iter()
        .filter(|s| s.owner.is_some())
        .filter(|s| s.camera_frame_at.is_some_and(|t| now.saturating_duration_since(t) < CAMERA_ACTIVE_WINDOW))
        .count()
}
```
