# Wii U Connect

Turn up to four smartphones into Wii U controllers for the [Cemu](https://github.com/cemu-project/Cemu) emulator on Windows:

- **Phone 1:** a Wii U GamePad (streamed GamePad screen, touch input, sticks, buttons, motion)
- **Phones 2–4:** Wii Remotes (original button layout, camera-based TV pointing, motion)

This project is under active development. See [`docs/progress.md`](docs/progress.md) for what works today.

> Wii U Connect does not include and will never distribute Nintendo games, system files, or console keys.
> You must supply your own legally dumped files.
